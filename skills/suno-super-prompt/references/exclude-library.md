# EXCLUDE library

Build EXCLUDE from blocks: **base** + **genre guard** + **intro/ending** + **voice guard** + **theme SFX**. Aim for 15–25 items. Exclude what Suno *tends to add*, not everything you can imagine — a 60-item list eats the 1,000-character budget STYLE needs.

## Base (always first)

```
crowd noise, audience, applause, crowd chants, no crowd
```

Add when the song should feel like a studio record: `live ambience, live venue ambience, concert ambience`.

## Genre guards

| Song type | Exclude |
|---|---|
| Emo / post-hardcore radio rock | `metalcore dominance, excessive screaming, deathcore vocals, trap drums, rap vocals, synth-pop dominance, glossy pop sheen, EDM drops` |
| Heavy modern metal (keep it musical) | `generic chug breakdown, endless chugging, nonstop screaming, blast beats, EDM drops, trap hi-hats, orchestral intro, robotic tuning` |
| Thrash / "tr00" heavy metal | `synths, orchestra, trap drums, EDM drops, glossy pop vocals, generic breakdowns, endless low chugs, brickwall compression, constant screaming` |
| Dark electronic metal | `EDM drops, festival EDM drops, orchestral swells, vocal chops, glossy pop vocals, excessive runs` |
| Modern sound wanted (not retro) | `grunge, loose garage drums, retro production, retro garage sound, shoegaze` |
| 80s-flavoured but not cheesy | `cheesy retro pastiche, cheesy retro effects, saxophone, disco` |
| Electropop alt version | `distorted guitars, metal riffs, screaming, festival EDM drops, vocal chops` |
| Ballad with band (not acoustic) | `acoustic-only softness, sleepy acoustic softness, choir layers, melodramatic orchestration, flashy guitar solos` |

## Intro / ending

| Want | Exclude |
|---|---|
| Heavy from beat one | `slow intro, soft intro, ambient opening, ambient fade-in, whispered opening, clean intro, synth intro, bass-only intro, long intro, orchestral intro` |
| Short instrumental intro (no cold open) | `cold open, long ambient intro` |
| Hard ending | `fade-out` |

## Voice guards

| Want | Exclude |
|---|---|
| One male rock singer only | `female vocals, duet, guest singer, choir, gang vocals` |
| Rock voice over R&B groove | `R&B vocals, soul vocals, soul runs, melisma, vocal runs, crooning, breathy falsetto, gospel ad-libs` |
| Natural voice | `robotic tuning, robotic vocals, excessive vocal runs, overproduced vocal stacks` |
| Guest sings only their section | `overlapping singers, alternating voices within sections, mixed backing vocals` |
| Guest rapper only in their verse | `overlapping lead and rapper, melodic guest rap` |
| No rap at all | `rap, rap verses, spoken sermon` |

## Theme sound effects (always check)

Suno loves to illustrate the lyric literally. Exclude the sound of the story:

| Theme | Exclude |
|---|---|
| War, soldiers, deployment | `gunfire, explosions, military samples, marching drums, patriotic anthem` |
| Hospital, illness, death bed | `hospital samples, heartbeat monitor, sobbing effects` |
| Prison, life sentence | `prison sounds, theatrical elderly voice` |
| Killer / villain narrator | `horror sound effects, evil laughter, spoken villain monologues, villain laughter` |
| Sex / depravation | `sexual sound effects, moaning samples, explicit sexual language` |
| Religion / sin imagery | `spoken sermon, choir` |
| Action-movie soundtrack | `movie sound effects` |
| Phone calls, distance | `phone ring samples, dial tone` |

## Lyric-quality excludes

Suno barely uses these, but they cost little and keep the brief coherent when the user complains about the words:
`forced rhymes, overly poetic phrasing, abstract metaphors, generic AI wording, fantasy imagery, gothic clichés, long lyric lines` (or `very short lyric lines` when the complaint is the opposite).

## Instrument removal (copy-ready)

- No bass: `electric bass, synth bass, bass solos, slap bass`
- No acoustic guitar in a heavy song: `acoustic guitar, fingerpicking, strummed intro`
- Acoustic lock: see `special-versions.md`.
