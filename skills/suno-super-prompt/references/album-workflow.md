# Album, EP and single workflow

## 1. Artist profile (once per project)

Collect or confirm, then reuse in every prompt:

- Band name and era (debut? 4th album after an emo record, a post-hardcore record and some metalcore singles?).
- 3–6 references, each with *what* to take from it (vocal grit, riff style, arena hooks, groove).
- Vocalist: register, texture, signature (e.g. "raspy male tenor, punk bite, rasps open on high notes").
- Lyric language (default English) and words the user has banned.
- Recurring production wishes (bass up front, double kick, drop tuning, no crowd).

## 2. Concept first

For any release, before writing prompts:

- **Title + one-line thesis** ("A life that looks perfect on paper, that you're still learning to live").
- **Narrative arc** across tracks — each song moves the character forward. Example arc for a 4-track EP: change how you see where you came from → question the life you built → rediscover joy with friends → decide how to live from now on.
- **Sonic direction** and how it *evolves* across the record (e.g. electronics start discreet and take over as the protagonist is replaced).
- **Tracklist with one line per track**: story + function.

Album role checklist (12 tracks): opener/manifesto, 2–3 big singles, 1–2 festival songs, 1 classic ballad, 1–2 deep emotional tracks, the band's "signature" track, title track near the end, epic closer. Optionally a bonus acoustic/alt version and a deluxe remaster.

For a concept EP you can also specify per track: structure, direction and a "story detail" — a single concrete image that makes the track unforgettable (e.g. "the family brings a photo taken that morning. He's in it.").

## 3. Track pitch (when the user asks "what's next?")

Give: title, 3–4 sentence story, the chorus hook line, BPM + sonic signature, and how it connects to the previous track. Don't write the prompt yet.

## 4. One SUPER PROMPT per turn

Stop after each prompt. Wait for "next track" / "próxima faixa" or feedback.

## 5. Unity without repetition

- Shared palette: same vocalist description, same tuning family, recurring production words.
- Vary on purpose: tempo (76–176 BPM range), opening type (riff / sung hook / beat-one vocal / instrumental intro / fake-out), structure, chorus entry point.
- Motif callbacks: a riff from track 1 returns as a synth motif in track 5; the closer's solo quotes the opener's melody.
- When the user says "different but with unity", change genre flavour and structure but keep vocalist, darkness level and one motif.

## 6. Release questions you should be ready to answer

- **Which track gets the music video?** The one with an immediate visual conflict, a strong hook and room for band performance. Pitch the video idea in 3–4 sentences; a second, more intimate video can follow.
- **Is the EP finished?** Check whether the arc has its final movement (decision/action, not another reflection). Recommend the count that serves the story; a 5th track must add something strong.
- **Bonus version?** Choose the song whose meaning flips in the new arrangement and position it as an epilogue.
- **Release title** — short, from a lyric that carries the thesis.
- **Sequence** — list it with the bonus clearly marked.
- **Follow-up single a year later** — keep the essence, raise one dimension (heavier, darker, poppier) and continue the character's story honestly (consequences of the last record).

## 7. Cover art direction

If asked for cover art (by an image tool):
- Avoid "AI look": sepia/brownish grading, glossy faces, perfect symmetry, generic fantasy.
- Prefer a concept from the record (a crumpled portrait for "Good on Paper"), photographic or graphic-design language, real typography.
- When the user names a band's visual style, translate it into design terms (typography, palette, composition), not a copy of their artwork.

## 8. Hand-off prompt

When the user wants to continue in a new conversation, produce a single copy-paste brief: role, objective, references, vocalist, the critical rules (this skill's non-negotiables), the banned words collected so far, and the step they're on.
